# SignSense24
SignSense Pro is an AI-powered sign language communication platform using MediaPipe and TensorFlow.js for real-time gesture recognition.
SignSense Pro is an AI-powered sign language communication and learning platform designed to bridge the gap between sign users and non-sign users through real-time intelligent interaction. The system combines computer vision, machine learning, and an immersive web interface to create an accessible communication ecosystem.

It features real-time Sign-to-Speech translation using MediaPipe Hands and TensorFlow.js, detecting single and dual-hand gestures through 3D landmark analysis, orientation tracking, finger-direction mapping, and custom gesture recognition. Users can build their own datasets, capture hand signs, train personalized neural network models, and perform live recognition directly in the browser.

The platform includes advanced capabilities such as:

Custom Gesture Dataset Creation with live sample capture
Neural Network Training in-browser for personalized sign recognition
Dual-Hand and Orientation-Invariant Recognition for robust performance
Finger Direction & 3D Gesture Analysis for detailed motion understanding
Text-to-Speech Output converting recognized signs into spoken language
Interactive Dashboard with modules for Sign-to-Speech, Speech-to-Sign, OCR Text Reading, and Sign Learning
Modern Futuristic UI featuring live AI status indicators, glassmorphism dashboard, animated visualizations, and responsive design

Beyond recognition, SignSense Pro acts as an assistive and educational ecosystem, supporting communication accessibility, sign language practice, and intelligent human-computer interaction. It is designed for applications in inclusive education, accessibility technology, assistive communication, and AI-powered gesture interfaces.

Tech Stack: HTML5, CSS3, JavaScript, TensorFlow.js, MediaPipe Hands, Web Speech API, Browser-based Neural Networks.
